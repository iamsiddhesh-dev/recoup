One call per failure — the obvious design — would be {{ view.per_payment_calls | int_comma }} requests per run, about {{ view.over_budget }}× Gemini Flash's daily allowance of {{ 20 }}. So the work is batched instead: every unmapped error in one request, the copy matrix in one per language, and every case explanation in one more. The free tier made the naive design impossible, and the design it forced is better — a model given the whole population at once is more consistent than one asked the same question a thousand times.

These counts are not a record of what happened during the run. Each cached response is put back through the same validator the run used, on every load of this page. Weaken a check and these numbers move.

The plan called for a hosted tracing service. The response cache turned out to be the better artifact: it holds the exact system prompt, the exact user prompt and the exact response for every call, content-addressed and committed to the repository. A dashboard behind a login is worse evidence than a file the reader already has — about {{ view.total_tokens | int_comma }} tokens of it, across {% for p in view.providers %}{{ p }}{% if not loop.last %} and {% endif %}{% endfor %}.
