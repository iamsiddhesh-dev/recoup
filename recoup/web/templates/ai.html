Why this page instead of a tracing service

The plan called for Langfuse. Then the response cache turned out to be the better artifact: it holds the exact system prompt, the exact user prompt and the exact response for every call, content-addressed and committed to the repository. Anyone who clones this can read what the model was asked and what it said — offline, with no account, years from now. A hosted dashboard behind a login is worse evidence than a file the reader already has.

The counts above are not a record of what happened during the run. Each cached response is put back through the same validator the run used, on every load of this page. Weaken a check and these numbers move.
